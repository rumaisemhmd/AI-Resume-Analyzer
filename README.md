# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer built with Python and Django that compares resumes with job descriptions, calculates an ATS match score, identifies missing skills, and generates downloadable PDF reports.

## 🚀 Features

- Upload resumes in PDF and DOCX formats
- Extract resume text automatically
- Add job descriptions
- AI-based resume and job matching using TF-IDF
- ATS compatibility score
- Detect matched and missing skills
- Personalized resume recommendations
- Download analysis report as PDF
- Responsive Bootstrap UI
- PostgreSQL database support
- Live deployment on Render

## 🛠️ Tech Stack

- Python
- Django
- PostgreSQL
- HTML
- CSS
- Bootstrap 5
- Scikit-learn
- ReportLab
- Git & GitHub
- Render

## 📂 Project Workflow

1. Upload Resume
2. Extract Resume Text
3. Add Job Description
4. Analyze Resume
5. Calculate ATS Match Score
6. Detect Matched & Missing Skills
7. Generate Recommendations
8. Download PDF Report

## ▶️ Installation

bash
git clone <your-github-repository-url>
cd AI-Resume-Analyzer
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
